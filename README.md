# YGP工具箱

一个简洁实用的Web文本处理工具集。

## 功能介绍

### 📋 JSON格式化
- 将单引号文本自动转换为双引号版本
- 自动格式化JSON，美化输出
- 支持任意JSON格式

### 📝 List格式化
- 将多行换行文本转换为JSON数组列表
- 自动去除空行和首尾空格
- 输出格式化的JSON数组

### 🗜️ 文本压缩
- 支持换行转空格（默认）：将多行文本合并为一行，换行符替换为空格
- 支持移除所有空白：移除所有空格、换行符、制表符等空白字符
- 支持换行压缩：移除空白行，保留内容行间的单个换行
- 自动去除首尾空格

### 🔄 文本去重
- 支持按行去重（默认）：去除重复行
- 支持按空格去重：去除重复词
- 显示去重统计信息（原始项数、去重后项数、重复项数）

### 🔢 数字求和
- 支持多行数字求和
- 支持空格分隔的一行数字求和
- 支持整数和小数
- 显示求和过程和结果

### 📊 CSV转Excel
- 将CSV格式文件转换为XLSX格式Excel文件
- 支持上传CSV文件（点击或拖拽）
- 支持直接粘贴CSV文本内容
- 转换后可预览数据并一键下载XLSX文件

### 🔍 文本差异对比
- 左侧输入框输入原文本
- 右侧输入框输入新文本
- 点击"对比"按钮执行对比
- 高亮显示差异结果：
  - 绿色背景：新增的行（+）
  - 红色删除线：删除的行（-）
  - 灰色：未变更的行（带行号）

### 🗃️ SQL格式化
- 自动格式化SQL语句，提升可读性
- 关键字自动大写（SELECT、FROM、WHERE等）
- 主要子句自动换行（SELECT、FROM、WHERE、JOIN等）
- SELECT字段逗号后自动换行并缩进
- CASE WHEN语句自动缩进
- 清理多余空白字符

### 📖 键值对转字典
- 将键值对文本转换为Python字典格式
- 每行一组键值对，使用Tab或多个空格分隔键和值
- 输出标准的Python字典字符串：`{"key1":"value1","key2":"value2"}`
- 识别失败的键值对会有警告提示

## 使用方法

### 方式一：直接运行EXE（推荐）
1. 双击运行 `YGP工具箱.exe`
2. 在左侧选择需要的工具
3. 在中间输入框粘贴或输入文本
4. 点击"处理 →"按钮执行转换
5. 在右侧查看结果，可点击"复制结果"按钮

### 方式二：浏览器打开HTML
1. 直接在浏览器中打开 `index.html` 文件
2. 操作步骤同上

## 快捷键

- `Ctrl + Enter`: 执行处理

## 打包说明

如需重新打包EXE文件，请运行：
```bash
# 方式一：双击运行
build.bat

# 方式二：命令行运行
pip install pywebview pyinstaller
pyinstaller ygp-tools.spec --clean
```

打包后的EXE文件位于 `dist` 目录下。

## 技术栈

- 前端：纯HTML/CSS/JavaScript
- 桌面框架：PyWebView（Python）
- 打包工具：PyInstaller

## 扩展性

工具采用模块化设计，可以轻松添加新工具：

1. 在HTML的sidebar中添加新的工具按钮
2. 在JavaScript的`processText`函数中添加对应的处理逻辑
3. 实现具体的转换函数
